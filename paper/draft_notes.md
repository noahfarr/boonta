## Conceptual points requiring follow-up

- **Closest prior work:** Gato already uses observation masking, specifically for
  nontextual observations while retaining text targets. ActObs already studies
  action-only versus joint supervision as initialization for subsequent RL and
  reports benefits from observation supervision. The draft acknowledges this
  overlap. Random-initialization pretraining is the planned setting, not proof
  of novelty or a guarantee of a different outcome.
- **Termination contract:** The current dataset serializer scores assistant
  `im_end` markers and a trailing newline. Exact BC of the deployed policy
  requires that every scored suffix token is generated by that policy. If the
  deployment adapter inserts the newline after stopping, mask the newline in a
  future implementation. The paper explicitly states this condition; this task
  has not changed training code or chosen the final deployment protocol.
- **Provenance:** Assistant roles are used as provenance labels. Audit ambiguous
  tool wrappers, missing reasoning, upstream truncation, and whether a recorded
  ending is an agent stop decision. Complete recorded interactions are not
  automatically complete upstream episodes or successful demonstrations.
- **Comparison interpretation:** All-token CLM includes prompt and framing
  targets, whereas ActObs masks prompts. Our planned comparison therefore does
  not isolate only post-action environment feedback relative to that prior work.
- **Normalization:** The exact decomposition is for summed likelihoods. The
  current implementation uses a supervised-token mean per minibatch; its
  denominator changes with the mask and affects stochastic update weighting.
  Hold the stated convention fixed and report target counts and training budgets.
- **Context selection:** Whole-record filtering preserves preceding history for
  retained examples but excludes long records. Final context length, retained
  source composition, immutable dataset revision, and task-disjoint evaluation
  must be established before reporting an experiment.
- **Empirical hypotheses:** Capacity competition, undesirable behavioral biases,
  improved policy initialization, RL sample efficiency, and any performance
  advantage require evidence. Observation prediction may instead improve
  representations and exploration. Policy consistency alone proves none of
  these comparative claims.
