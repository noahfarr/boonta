Distributed reinforcement learning in JAX, built on the Podracer architectures. Pick a pilot, a pod and a track above, and boonta's real training code runs in your browser.

PILOTS · PODRACERS

Pick the pilot that fits your environment

Each pilot is a podracer: it owns the training loop and every device. Pods (the algorithms) never see it, so switching pilots is one config line.

ANAKIN

Acting, environment steps and learning compile into one program, split across every device.

Use it forJAX environments, end to end on the GPU

SEBULBA

Actor threads collect rollouts on some devices while learners train on the rest and send back fresh parameters.

Use it forSlow or non-JAX environments, acting and learning asynchronously

QUADINAROS

Trains on recorded data, held in memory or streamed from disk, and only touches the environment to evaluate.

Use it forFixed datasets, for offline RL and behavior cloning

SPEED

Most simulators train at millions of steps per second

The garage above runs on your CPU in WebAssembly. On a GPU the same code runs a hundred times faster.

QUICKSTART

Three commands to a training run

Clone, install with uv, then train PPO on MinAtar Breakout. Swap algorithm= and environment= for any pair below.

terminal
$ git clone https://github.com/noahfarr/boonta && cd boonta
$ uv sync
$ python hangar/main.py algorithm=ppo environment=gymnax/minatar/breakout
